# Курс ИИ-инженера — мультфильм из 16 серий

Длинный обучающий курс на русском языке в стиле мультфильма: оранжевый талисман «Клоди»,
псевдо-3D сцены, озвучка и музыка генерируются кодом. Видео в репозиторий не кладутся
(`ai-course/out/` в `.gitignore`), хранятся только исходники.

| 2 | Как машины учатся |

(code.claude.com/docs, platform.claude.com/docs). Эта область быстро меняется,
поэтому команды и настройки стоит перепроверять по актуальной документации.

## Устройство

```
ai-course/
  engine/            движок
    core.js            тема, карточки, значки, тени, фон
    mascot.js          талисман «Клоди» (настроения, моргание, речь)
    g3.js              мини-3D: камера, сфера, линии, коробки, пол
    icons.js           векторные иконки
    scenes.js          типы сцен (hero, cards, flow, compare, list, table, terminal, code, …)
    scenes3d.js        3D-сцены (нейрон, сеть, эмбеддинги, внимание, дорога, …)
    main.js            покадровый рендер (режимы still и range)
    tts2.py            озвучка эпизода -> timeline.json + narration.wav
    audio.py           обработка голоса, музыка, эффекты, сведение
    build.py           сборка серии целиком (озвучка, рендер, mux, главы, .srt)
    eplib.py           помощники для текстов серий
    pron.json          словарь произношений латиницы и сокращений
    stress_fix.json    правки ударений
  episodes/e01.py … e16.py   сценарии серий (сцены и реплики)
```

## Как собрать серию

Нужны: Python 3 с `onnxruntime`, `numpy`, `num2words`; `espeak-ng`; `ffmpeg`;
Node.js с `@napi-rs/canvas`; голос Piper `ru_RU irina medium`.

```bash
export NODE_PATH=<путь к node_modules с @napi-rs/canvas>
python3 engine/build.py e13 <рабочая_папка> <папка_голоса> <node_modules> out
```

Результат: `out/E13_<Название>.mp4` (1920×1080, 30 к/с, главы внутри файла) и `.srt`.

## Как написать новую серию

Серия — это список сцен. У каждой сцены есть список реплик (`B("текст", mood=…)`),
а элементы на экране привязываются к репликам через `at` (номер реплики или
`[номер, секунды]`). Латиницу в репликах нужно либо добавить в `engine/pron.json`,
либо писать в форме `{как на экране|как произносится}`.
