# Telegram-бот «Тени»

Бот работает вместе с приложением: правит те же дела и темы через облако. Пишешь ему обычным текстом, и дело появляется в приложении. Закрываешь дело в приложении, и бот перестаёт напоминать.

## Что умеет

- **Оформление:** без значков в тексте, заголовки жирным, списки в цитатах, время моноширинным, в карточках памяти ответ скрыт «спойлером» (тап открывает). Первая строка каждого сообщения самодостаточна, потому что именно её видно в уведомлении на экране блокировки.
- **Просто пиши дело:** `сдать лабу в пятницу в 18:00`. Несколько дел с новой строки. Под ответом кнопка «Отменить». Разбор текста тот же, что в приложении.
- `/today` сегодня и хвосты, у каждого дела кнопки «Готово» и «Завтра»
- `/soon` ближайшие две недели
- `/memory` проверка себя прямо в чате: карточка, «Показать ответ», оценка в один тап (модель памяти та же)
- **Утренняя сводка** (7, 8, 9 или 10 часов), **напоминание за 30 минут** до дела со временем, **вечером про завтра**
- `/settings` сводка, напоминания, тишина, часовой пояс
- Кнопка меню «Тень» и `/app` открывают приложение прямо внутри Telegram (нужно включить GitHub Pages)

Отвечает только владельцу: чужим пишет «личный бот», группы игнорирует.

## Запуск (5 минут)

1. В Telegram у `@BotFather` выпусти **новый токен** бота (`/revoke`, затем выбери бота). Старый токен, который был отправлен в чат, считай скомпрометированным.
2. В репозитории открой **Settings → Secrets and variables → Actions → New repository secret** и добавь:
   - `TG_TOKEN`: новый токен бота
   - `FB_EMAIL` и `FB_PASSWORD`: почта и пароль, которыми ты входишь в «Тень» (бот входит как ты, поэтому видит те же данные)
3. Открой вкладку **Actions → Telegram-бот → Run workflow**. Дальше он сам запускается каждые 5 минут.
4. Напиши боту `/start`. Он ответит твоим `chat id`. Добавь его секретом `TG_CHAT_ID`. До этого бот никому, кроме подсказки с id, не отвечает.
5. Снова `/start` и выбери часовой пояс.

Пока секретов нет, процесс просто спит и ошибок не шлёт.

## Как это работает и чего ждать

GitHub Actions запускает бота на ~5 минут, и он слушает Telegram всё это время, поэтому пока процесс идёт, отвечает за секунды. Расписание GitHub иногда опаздывает на несколько минут, и тогда между запусками бывает пауза: сообщение дождётся, а напоминание придёт чуть позже. Репозиторий публичный, минуты бесплатные. Шаг в конце процесса не даёт расписанию заснуть через 60 дней без коммитов.

Если нужны мгновенные ответы без пауз, бота можно перенести на Cloudflare Workers (вебхук). Логика в `bot/bot.mjs` для этого не меняется.

Состояние бота (часовой пояс, настройки, что уже отправлено) лежит в облаке рядом с делами, в документе `users/{uid}/pv/bot`.

## Проверка

```bash
node bot/test/bot.test.mjs
```

Запускает имитации Telegram и Firebase и проверяет доступ, добавление, кнопки, память, синхронизацию, напоминания, настройки и основной цикл.
